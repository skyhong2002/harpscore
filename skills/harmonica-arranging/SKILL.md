# Harmonica arranging

Read `references/workflow.md` and `references/arranging.md`. For Jianpu read `references/jianpu.md`; before delivery read `references/verification.md`. The optional fixed-C profile is in `references/fixed-c.json`. These references are bundled from the matching project release.

Ask only for missing information that changes the musical result. At minimum identify source, instrumentation and player level. Use an explicitly selected profile; fixed-C and beginner simplification are options, not universal defaults.

Keep transcription, musical adaptation, engraving and audio rendering distinct. Preserve phrases in beginner duets. Bass sustain must preserve groove, not flatten every note to two or four beats. Chord rhythm can carry percussion and offbeats.

For layout-only changes preserve actual pitch, onset, duration and velocity. For numbered notation verify octave reference, accidentals, quarter-beat underline gaps and alignment in the actual renderer; XML grouping alone is insufficient. Transparent native-note plus text overlays require explicit semantic comparison after edits.

Discover local MuseScore version and export constraints. Preserve unsaved scores and unrelated works. Do not automatically repeat failing exports or treat a generated file as proof of clean export. Respect any PDF pause. Deliver only requested editions and report verification limits.

This skill provides instructions, not an installed transcription engine. Do not invent scripts, claim automatic audio-to-score support, or publish third-party music under the toolkit's license.
