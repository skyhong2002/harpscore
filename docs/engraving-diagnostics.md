# 元素碰撞與過寬小節的診斷

適用五線譜、簡譜與兩者並用的重奏總譜；沿用所選 profile 的字級、部距、和弦位置與八度記法。本流程落實 [V06、V14、V15](verification.md)，不提供或假定已存在自動判斷全譜無碰撞的工具。音樂來源核對仍依 [來源驗證](source-verification.md) 另行完成。

## 先固定要驗證的版本

保存修改前的可編輯檔與雜湊，記錄 MuseScore、字型、profile、頁面大小及縮放。保留使用者手動改音；不要從舊範本重新生成而覆蓋它們。讀取目前正常視窗的實際排版，幾何資料、畫面與待交付檔必須對應同一版。重新分行或重開使排版改變後，舊頁碼與幾何不能直接當成新版證據。

若現有工具能讀出 renderer 的字形、線段、頁、系統與小節邊界，先確認座標使用同一尺度、同一頁面原點；跨頁不能只比較數值相同的座標。曲線與跨行八度線須逐段處理。若讀不到實際幾何，就直接在正常 MuseScore 視窗逐頁檢查，記錄人工觀察；不要為補資料而啟動未知轉檔器或恢復使用者暫停的匯出。

## 以幾何找候選，再看畫面

元素外框相交或距離很近只是候選：曲線外框可能包住大片空白，斜線和數字的外框也不等於實際墨跡。反過來，框未相交仍可能因距離太近而難讀。記錄候選的位置、所屬部、元素種類及涉及的鄰部，再放大確認實際字形或線段。

先排除有意接觸，但排除必須限於具體關係，不能把整類元素忽略：

| 有意接觸 | 白名單的界線 |
| --- | --- |
| 音桿連到音頭、橫桿連到其音桿 | 只限同一音符或同一連桿群；碰到鄰音或鄰部仍檢查 |
| 延音線／圓滑線接近所屬音的端點 | 只限對應起訖音附近；線身穿過數字、臨時記號或其他聲部仍是候選 |
| 連音組橫桿及數字所屬的同一組 | 數字與橫桿按樣式留斷口，不得因同組就接受壓字 |
| 按指定樣式接續的譜線與小節線 | 確認確為應連通的邊界，不能用它掩蓋文字或音頭碰撞 |

每個候選分別記為「已確認需修」「有意接觸」「畫面清楚但幾何誤報」或「仍待確認」，附位置與理由。不要以某個固定距離、零候選數或白名單數量宣稱全譜無碰撞。

放大時至少檢查：

- 力度文字與漸強弱線是否貼近自己的聲部，且不碰到下一部的音符或上一部的連線。
- `8va`／`8vb` 文字、虛線、尾鉤及跨行續段，是否屬於正確聲部；高音加線或八度點是否把八度線推到鄰部。
- `tr`、延伸波線與終點，是否碰到連線、八度線或上方部別。
- 連音組的橫桿、括號與「3」等數字，是否靠近本組音符；密集段、休止起頭及跨行位置需單獨看。
- Chord 和弦代號是否靠近本部節奏：五線譜依約定在節奏上方，簡譜依選定 profile 在節奏下方。也要看與 Bass 的間距，不能只量代號到叉叉的距離。
- 雙音上下連線、簡譜八度點、減時線及臨時記號，是否互相穿越；小節線是否跨需要連接的各部連通。

## 找出過寬的小節

先巡覽全頁，找前段稀疏而尾段擁擠、少音小節被拉長、末行單獨留下很少小節等現象。接著以**同拍號、同編制、同字級與相近內容**的小節作比較；拍號相同但裝飾音、和弦標示、換調或節奏複雜度不同，仍須分組或註記。

若取得同版幾何，列出每小節實際寬度，以及全體顯示聲部共同需要的水平位置。統計應考慮不同起音位置、最短細分、裝飾音、休止、連音組、臨時記號、和弦與其他文字；不能僅將各部音符總數相加，也不能把全休止小節當作零排版需求。全休止仍有小節時長、拍點對齊、休止或延長符號，並可能承接跨小節線段。

可以比較同組小節的寬度、寬度中位數與可見內容密度，將「較少內容卻顯著更寬」列為待看離群值。這是排序方法，不是通用密度公式或必須壓縮的門檻。遇到第一小節的樂器名／調號、長和弦名、換拍、換調、排練記號、弱起、跨行邊界或尾小節，先查明額外空間的原因。

同時看整個系統：若所有小節都被均勻拉寬，可能是固定換行過早；若只有某一小節過寬，可能是局部 stretch 或某個文字的避碰空間。即使每小節寬度都正常，部距或系統間距不均仍須在全頁處理。

## 小幅修改，重新驗證

1. 選一段稀疏行及一段密集行試排。先查局部 stretch、強制換行／換頁、元素偏移與自動避碰，再作最小修改。少音段可試多放一小節，不能把固定每行四或五小節套遍全曲。
2. 調整後檢查該行、前後行及頁尾。不要藉由縮小全譜、刪除必要記號或改音來消除碰撞；不得把空間全分給最後一小節。
3. 比對改前後全曲 performed pitch、起音、時值、力度及 voice，保留雙音重複音、裝飾音、連音與起訖；另確認速度、力度等控制與播放設定未因排版改動而改變。若有經授權的音樂修正，單獨列出，不能混入「純排版不變」。
4. 正常儲存、關閉、重開最終檔。巡覽**所有實際頁面**，記錄頁數與各頁小節範圍；再以 100% 或更高倍率查看代表段、所有修過的位置與跨行接縫。大幅重新分行後不能只看首頁與尾頁。
5. 將「全頁巡覽」「放大細節」「來源對照」「資料差分」「實際聽音」分別記錄範圍與版本。例如一份二十頁總譜，應記全二十頁巡覽，再列出三連音、八度終點、密集雙音、特殊連音組及末頁的放大位置；不能把二十頁縮圖都看過寫成每個細節已逐一放大。

## 可沿用哪些證據

沿用舊視覺證據必須說明版本差異。如果可編輯容器僅改播放設定，已逐一確認其餘所有成員與已檢查版本完全相同，可保留既有版面證據並記錄橋接雜湊；這不代表新音量已實際聽過。若音符、文字或樣式改變，就不能套用這個理由，需驗證受影響處及可能重新流動的頁面。

公開文件只記方法與合法最小案例，不放入使用者私有路徑、第三方完整樂譜、原圖或未授權畫面。沒有同版實際 renderer 或畫面證據時，保留「待檢」；不宣稱工具已自動完成驗收。

## 實際幾何的分層提案工具

`scripts/engraving_lanes.py geometry.json report.json` 讀取正常 MuseScore 幾何 reader 的 `rows`、`otherSpanners`，不改譜、不匯出媒體。座標需為同頁原點、以 staff space 表示。它按頁隔離碰撞候選，保留跨部及相鄰大行候選，並依數字／升降／八度點、連音組、重音、⑧、拍號預留垂直層。連音組數字和橫桿一起提議平移；巢狀連音組自身已壞的間距仍須另檢，不聲稱共同平移能修復它。

提案會回報侵入前一部時所需的額外間距；不可只套用記號位移而忽略此需求。此工具使用保守的外框，可能把合理相接列為候選，也未包含所有曲線墨跡及缺失元素。先視覺確認候選、在副本套用選定提案，再重新讀取幾何和巡頁。首次在實際重奏尾段已找到拍號與八度線相交；這不是全曲自動排版完成或全譜無碰撞的證明。

輸入適配目前針對既有簡譜覆層：8／8.8 pt 數字視為連音標籤，空文字且負 y 的 TextLine 視為上方連音橫桿。這些是此覆層的約定，不是 MuseScore 通用識別規則；其他編輯方式必須先更換分類器。輸出記錄輸入幾何的 SHA-256，仍需另行記錄對應譜檔雜湊。試排已證實相同位移套到另一大行可能產生新碰撞，因此提案不可直接作為全曲自動修復。

連音組內部也須檢查：依相同頁／行／聲部、水平範圍與最近垂直邊界配對標籤和橫桿；不明確的配對跳過並人工核對。先讓「3」字形離開自己的橫桿，再讓外層括號避開內層標籤。`tuplet_proposals` 只回報這些位移；重新渲染後才使用 `local_mark_proposals`，按實際水平相交範圍移動重音、八度線與拍號，避免把所有記號一起拉高。跨部檢查也包含幾乎相接的水平細縫。可見延音／圓滑線外框列為候選及避讓障礙，但曲線外框相交仍不等於墨跡相撞；端點修正必須保留原生連接音。

三連音橫桿還需避開本組數字的升降記號與八度點；括號和標籤作對應調整後重看重音。計算前一部的佔用邊界時，包含力度線及曲線等所有可見幾何，不能只計數字／文字。碰撞搜尋需涵蓋同頁相鄰大行；分頁可隔離，大行之間不能當作永不相撞。跨大行結果目前只供檢查，不自動改行距。

換行延續段須獨立量測：原生 Tie／Slur 的首段已有偏移，不代表 renderer 新產生的後段也沿用；短延續段可能回到零偏移而壓住行首數字。依該段實際上下方向、字形外框與連接音定位，僅修正受影響段，保留連音兩端及播放。移開數字後仍要檢查八度點、升降記號與鄰部，不以「曲線／數字候選已消失」代替整體通過。

局部部距或大行間距修改可能使整行換頁，並改變其他頁的均分間距。每次修改後重新量測全曲同頁的跨行候選，對照前後報告區分已消除與新出現的位置；不得只重查原碰撞座標。先在候選副本迭代，再正常儲存重開，核對完整音樂事件、控制與音色設定。候選數降低只是進度，剩餘候選與未巡覽頁面仍須明確列為待檢。

沒有碰撞也可能有不均勻的大空白。`system_spacing` 以每行所有已量測字形／線段的最上、最下邊界計算行間空白，不以譜表基線距離代替。至少三行的同頁內，若某間距超過最小正間距兩倍、且多出四個 staff spaces，就列為 `review-excess-gap`；這只是可調的檢查門檻，不是強制均分。兩行頁、頁尾空白、標題與未量測元素不在此比較範圍。先檢查是否有殘留固定 spacer 或樂句分隔需要，再在副本縮減、重新量測全曲、核對受影響頁。不要為消除空白而移除記號或改音。

`accent_label_contacts` 專查同頁、同大行、同 voice 的重音與三連音數字：字形垂直範圍相交且左右間隙小於 0.35 staff space 時列為待看。這能找出尚未碰撞、卻像「3>」連成一個符號的情況。不要一律擴大所有外框的碰撞門檻，否則大量正常八度點、細線間隙也會被混入。先放大核對，再用局部提案調開，確認前一部的空間並重新量測；這個分類器僅適用目前覆層約定。

裝飾音記號不能只向上逃離障礙：移過連音橫桿可能反而撞到標籤或鄰部。`symbol_slot_above` 接受已明確核對的記號與所屬數字，試放在數字上方最近的空隙，允許向下移回橫桿下方；保持水平位置，並用同頁所有已量測元素檢查間距。空隙不足就回報阻擋項目，不猜測另一個位置、不自動拉開全譜。此函式須由呼叫者明確選定原生音符與數字的對應，不從字形相近推定語意。

實際試作中，關閉原生 autoplace 後的落點與原先框加上位移不一定相同；修改後必須重新讀 renderer，不能重複累加過期的位移。reader 的 articulation 清單可能也包含原生 Ornament，套用前須查回真正元素種類；震音等未被 reader 收錄的符號仍需畫面檢查，不能把「候選為零」當成完整覆蓋。
