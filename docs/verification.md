# 怎樣才算完成

## 音樂驗收

V01 · 與指定參考版本逐段核對：曲式、主旋律、和聲、副旋律、低音、開頭節奏與尾奏。中間表格與原生音符相同，不證明表格抄對原掃描。逐聲部核對來源，包含連音的前後端；不同編制的差異先依 `docs/source-verification.md` 分類。只說「聽起來像」不足以證明完整。

V02 · 每小節與每個聲部的時值正確；裝飾、連音、弱起與休止有明確處理。純排版版本比對改前後的音高、發聲起點、時值與力度，應完全一致。

V03 · 用實際樂器音域與演奏程度檢查可吹性。檢查換部是否完整接句，以及伴奏是否有承接被簡化的內容。

## 畫面驗收

V04 · 看第一頁、一般滿頁、最密段落與尾頁。放大檢查每拍減時線斷口、升降位置、x/X/0 基線、延音橫線中央、動態與和弦間距，以及靠近小節線的 0 和－。

V05 · 檢查開頭與結尾的小節大小、行首小節線、跨聲部垂直對齊、段落字母、頁首及頁數。MuseScore 首頁縮圖必須來自同版實際渲染，不能沿用來源五線譜縮圖。

V06 · XML 的條件正確不等於畫面正確。檢查實際線段與字形邊界；若沒有拿到新渲染，不把舊圖當成新版通過。正常 MuseScore 視窗截圖是實際渲染證據，PDF 不是唯一途徑。暫停匯出時，以同版儲存、重開及畫面檢查驗證本機譜，記錄版本雜湊和片段位置。

## 播放與交付

V07 · 在正常 MuseScore 視窗開啟並播放代表段落，核對起音、聲部平衡與音色。可播放檔與聽過的檔案要能對應到同一個版本。播放器運作、MIDI 事件比對、波形數值與實際聆聽分開標記；工具不能聽取音訊時，不宣稱已聽過。不得為了測試任意恢復使用者已暫停的音訊匯出。

V08 · 檔案存在、程序正常結束、樂譜可開啟、畫面正確與已發布是不同證據。輸出失敗停止並診斷，不因為檔案存在就宣稱輸出正常。

V09 · 交付前檢查版本清單、檔案雜湊、編制與命名。保留可編輯原檔。不要自行產生未要求的個別分部或恢復已暫停的 PDF 輸出。

V10 · 重奏換部需列出代表性 pickup 及其下一個落點，確認同一演奏者承接；另核對非主旋律部確實有內聲部或填句。雙音每音都須保留在原生發聲；五線譜逐音寫出，簡譜的非八度雙音逐音疊寫，選用八度簡寫時單數字加明確重奏記號。孔位／吹吸／滑鍵可行與真人試吹分開記錄。以實際字形檢查整組居中、八度點與上下連結線、部距及跨行延續。

V11 · 鋼琴有多個 voice 時，逐 staff、逐 voice 重新計算時間與連音；不同 voice 的同音不能互相覆蓋來源索引。獨奏鋼琴要核對旋律全曲完整，原譜伴奏的每個音是否按所記錄的改編保留。混合簡譜版與五線版的發聲事件必須相同，不能只驗第一個 voice。

V12 · 檢查八度與音色時，使用套用譜號移調、ottava 與樂器移調後的 performed pitch；不能只比較 MSCX 的 Note.pitch。Chord 的四音位及每音八度簧按多重集合核對，保留重複同音、每個起訖與原有裝飾音。先在正常視窗儲存、重開，確認實際音色資源仍正確；GM program 名稱、未啟用的舊播放欄位或容器內設定，不能單獨證明目前播放器發聲。

V13 · 檢查轉譯正確性時，證據必須含舊原譜與新版相同聲部、相同段落；只看新版不能證明抄對。把直接原圖閱讀、原生音樂差分及實際畫面檢查分別記錄，修過的音同步核對簡譜數字、升降與八度點。若具體錯段推翻舊報告，保留舊記錄並註明被哪些明確修正取代，不繼續引用它宣稱無誤。編輯提示關閉、字形正確與實際發聲正確各有獨立證據。

V14 · 排密或重新分行後重新檢查全曲實際分頁，另放大看三連音的橫桿與「3」、跨行連結線、八度虛線及力度線。原譜同段落、改前後完整音樂資料、正常儲存重開的實際畫面分別留證；三者不能互相替代。只抽查來源時明示抽查範圍，不把全頁排版檢查或原生資料相同寫成全曲來源無誤。

V15 · 元素碰撞與過寬小節依[版面診斷流程](engraving-diagnostics.md)處理。同版實際 renderer 的幾何資料只能找出待看的位置；框相交、間距閾值或音符數不能單獨判定通過。區分合理的音桿／橫桿接觸及連線端點，逐段確認力度、八度線、顫音、連音組與和弦代號沒有侵入鄰部。依同拍號、同編制及相近內容比較小節寬度，調整後保留完整音樂事件，正常儲存重開、巡覽全頁，再以 100% 或更高倍率檢查密集與跨行段落。

V16 · 全曲時間核對須包含實際小節長度、隱藏休止符和跨小節累計起點，不只比較「第幾小節的第幾拍」。特別檢查不完整連音組、弱起及超出拍號的小節；原生解析結果仍須與正常播放器的代表段落分開驗證。五線／簡譜的原始 Note.pitch 若因譜號或 Ottava 不同而不同，先比較完整 performed pitch 多重集合，再逐項分類剩餘屬性；不得一併忽略力度、發聲時值、延音端點或裝飾音。手動琶音線長等純圖形差異可以單列，但不能把未分類差異直接排除以取得通過。

## 修正一個問題時

保存使用者要求曲目的代表段落位置、profile、軟體與字型版本、預期效果、實際畫面，以及修改是否應影響播放。先對照真正 Summer 版式，再檢查新曲密集段落與全曲。公開回歸資料須有合法授權或只含最小語意案例，不公開第三方可編輯全譜；不以新寫原創四小節練習取代使用者的曲目。
