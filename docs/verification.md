# 怎樣才算完成

## 音樂驗收

V01 · 與指定參考版本逐段核對：曲式、主旋律、和聲、副旋律、低音、開頭節奏與尾奏。只說「聽起來像」不足以證明完整。

V02 · 每小節與每個聲部的時值正確；裝飾、連音、弱起與休止有明確處理。純排版版本比對改前後的音高、發聲起點、時值與力度，應完全一致。

V03 · 用實際樂器音域與演奏程度檢查可吹性。檢查換部是否完整接句，以及伴奏是否有承接被簡化的內容。

## 畫面驗收

V04 · 看第一頁、一般滿頁、最密段落與尾頁。放大檢查每拍減時線斷口、升降位置、x/X/0 基線、延音橫線中央、動態與和弦間距，以及靠近小節線的 0 和－。

V05 · 檢查開頭與結尾的小節大小、行首小節線、跨聲部垂直對齊、段落字母、頁首及頁數。MuseScore 首頁縮圖必須來自同版實際渲染，不能沿用來源五線譜縮圖。

V06 · XML 的條件正確不等於畫面正確。檢查實際線段與字形邊界；若沒有拿到新渲染，不把舊圖當成新版通過。

## 播放與交付

V07 · 在正常 MuseScore 視窗開啟並播放代表段落，核對起音、聲部平衡與音色。可播放檔與聽過的檔案要能對應到同一個版本。

V08 · 檔案存在、程序正常結束、樂譜可開啟、畫面正確與已發布是不同證據。輸出失敗停止並診斷，不因為檔案存在就宣稱輸出正常。

V09 · 交付前檢查版本清單、檔案雜湊、編制與命名。保留可編輯原檔。不要自行產生未要求的個別分部或恢復已暫停的 PDF 輸出。

V10 · 重奏換部需列出代表性 pickup 及其下一個落點，確認同一演奏者承接；另核對非主旋律部確實有內聲部或填句。雙音每音都須出現在原生播放與簡譜覆層，孔位／吹吸／滑鍵可行與真人試吹分開記錄。以實際字形檢查縮小的上下兩音整組居中、八度點居中，部別間距沒有因雙音被放大。

V11 · 鋼琴有多個 voice 時，逐 staff、逐 voice 重新計算時間與連音；不同 voice 的同音不能互相覆蓋來源索引。獨奏鋼琴要核對旋律全曲完整，原譜伴奏的每個音是否按所記錄的改編保留。混合簡譜版與五線版的發聲事件必須相同，不能只驗第一個 voice。

## 修正一個問題時

附上最短可重現的原創樂句、使用的 profile、軟體與字型版本、預期圖、實際圖，以及修改是否應影響播放。修正後先跑這個例子，再檢查一般頁面，避免用某首曲子的小節號修補所有作品。
