# 重排原譜與不同編制的核對

## 來源和中間資料分開

S01 · 建立原譜版本、頁碼、聲部、印刷小節與原生小節對照；弱起可能讓兩種小節號相差一。掃描圖、轉錄表、原生譜與渲染畫面各有版本雜湊。中間表格與 MuseScore／MIDI 一致只證明轉換一致，不能證明最初抄譜正確。

S02 · 直接閱讀原始掃描或原譜，逐頁、逐聲部核對音頭位置、升降、譜號、調號、連音、休止與裝飾音。先標不確定處；另一編制可定位疑點，但不能代替指定版本。來源允許的換行、分頁與可讀性改善不等於允許重作曲。

## 比較不同編制

S03 · 比較前先對齊弱起、速度、拍號、段落、反覆、移調樂器、八度譜號及 ottava。音高差異可能是轉位、內聲部、換部、刪減或不同的真正編曲，不能把四重奏強制複製到六重奏。區分「已確認抄錯」「真實編制差異」「仍待來源判讀」。

S04 · 先把所有時值寫成可比較的有理數，保留聲部、voice 和裝飾音身分。同拍位置的重複同音不能被字典鍵或集合吃掉。表格的文字拼法、寫譜音高、移調後發聲音高與和弦品質須分開；例如減七與增和弦的代號別名不能讀成另一種和弦。

S05 · 跨版本差異可以加快定位，但不能只檢查同節奏的音高差。二分休止與兩個四分休止會把相同延音段分進另一類，可能漏掉延續端錯音。修一條 tie 時追到整條連音鏈的真正 attack 與 release，兩端音高一致且不新增小節線 attack。之後仍需完整指定聲部的來源核對。

## 分三輪驗收

S06 · 第一輪原譜閱讀：列出確定改正的聲部、小節、拍點、前後音高／時值、升降狀態與來源位置。第二輪原生資料：以穩定事件身分精準修正，核對音樂差分只含已批准的改正，簡譜覆層同步更新。第三輪正常 MuseScore：儲存、重開，逐頁與放大片段檢查真正字形、連線及換行。可由獨立 agent 執行不同輪次，但要交代各自證據範圍；三份程式報告不等於三次來源閱讀。

S07 · 改 pitch／TPC 後也核對明示 Accidental 物件與小節內延續規則。只改播放音高可能留下錯誤升降字形；也不能不分情境把所有 forced accidental 刪掉。普通還原、提醒記號與跨小節重置分別處理。

S08 · 原始掃描、第三方可編輯譜與音訊留在作品的合法存取範圍；公開 HarpScore 只記通用方法、選用偏好與合法最小案例。來源譜的版權署名及編曲者不得被新抄譜者的署名取代。

S09 · 掃描紙張彎曲或傾斜時，每段音頭都以當地完整五條線重新定位置，不把整行共用的固定 y 座標當成音高。先讀唱名與八度，再套用調號、小節內臨時記號和譜號；無明示還原的 E／B 仍受降調號影響。重現段各自核對，不能因外形相似直接複製第一次的讀音。使用者指出具體錯段時，重新打開原圖與新版同段；先前的「全曲無誤」報告或表格一致不得取代這次閱讀。
