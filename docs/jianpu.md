# 簡譜的顯示規則

以下是本專案採用、可覆寫的簡譜規範；不同地區或團體可以建立別的 profile。固定調與首調都可記錄，但不能在同一版本中默默切換。

## 音高、升降與八度

J01 · 固定 C profile 使用 1=C，D 大調保留 ♯1、♯4。未加八度點的 1 對應哪個發聲八度，由樂器設定決定。使用者可選半音階 C5、DB H. C3，且不在頁面上顯示參考標籤。這些設定只改八度點，不改發聲。

J02 · 升降記號用小型上標，放在數字左上方，不以完整符號寬度擠開快速音群。同一小節同一唱名與八度只在升降狀態改變或還原時重寫。換小節重置；不同八度分別計算。

## 節奏與線條

J03 · 十六分音符緊密、八分音符稍分開、四分音符較寬。保留字形之間的最低間距，不能讓 x 與 0 黏在一起。各部同時發聲的位置仍需垂直對齊。

J04 · 每一拍的減時線都必須實際斷開。4/4 至少看得出前兩拍與後兩拍的結構；密集十六分音符按四分音符拍分組。少量容易理解的切分四分音符可合併連結的八分音符，但跨第三拍仍需清楚呈現。

J05 · 不可只檢查程式中的分組；在實際渲染的 SVG 或 MuseScore 畫面確認線段端點之間有空隙。調整數字位置時同步調整減時線起終點。

J06 · 延音用的「－」要對齊數字本體中央，寬度足夠辨識。不要從數字畫可見連結線到延音橫線。需要跨小節的延音應採一致的顯示策略，避免一串多餘弧線。

J07 · 附點放在增加時值的起點：第一拍起的附點四分音符，點放在第二拍的位置；附點八分音符的點在該音開始後半拍。這是本專案選定的空間記譜方式，演奏時值不變。

J08 · 數字與減時線只留約一筆畫的細縫；低八度點、減時線、力度分層，不能互相重疊。附點與八度點需可辨識，不要以極細小點代替所有語意。

## Chord 與文字

J09 · Chord 使用 x、X、0，三者明確對齊同一條底線。X 可表示已有的強擊；不得為了印出 X 改寫播放力度。速度門檻屬 profile 設定，並非通用音樂規定。

J10 · 代號依每小節起點與換和弦拍點定位；垂直位置由 profile 與當次指示決定。創始使用者最新要求 Chord 不印調號、代號在上方、音桿朝下，力度在下方獨立一層。代號貼近自己的 x／X 節奏，不能為了避線推到上方 DB H. 的音符或八度點旁；仍須留出可辨細縫，並檢查與三連音及延音弧線的交會。這取代早期代號放下方的偏好，不追溯宣稱舊範本已更新。Chord 與 DB H. 不必額外拉大距離，其他聲部要有足夠位置放力度及八度點。

J11 · 數字用筆畫粗細一致、易辨識的無襯線字體。可選 Avenir Next 或可取得的同類字體；不能假設其他人的機器已安裝商用字型。字型替換後必須重看基線、點與減時線。

## A4 排版

J12 · 依密度以約四小節一大行為起點，少音小節較窄、多音小節較寬，分配整行剩餘空間，不能把空間全丟給最後一小節。避免孤立的一至兩小節；不要每四小節硬換行。

J13 · 五重奏一般完整頁以約五大行試排，部別之間可緊湊，但大行之間仍需清楚分隔。第一頁依標題高度調整；最後不足一頁維持正常行距，靠上放，不撐滿整頁。這是起點，依實際字級與音符密度調整。

J14 · 各部的小節線連成一整條。只有第一大行顯示樂器名；後續各大行以單純小節線開頭，獨奏也需要。4/4 放在起始小節線上方，速度再高一些；小節號對齊開頭線的正上方，段落字母放更高以免碰撞。

J15 · 簡譜不用圖片。第二頁起上方有置中曲名，下方置中頁數含總頁數，例如「2 / 6」。標題、作曲及編曲署名清楚，避免把版本描述或說明長句塞入副標。

## 雙音和部別空間

J16 · 同一把半音階同時吹非八度雙音時，兩個數字都稍微縮小、上下疊寫，水平中心一致。兩數字的整組視覺中點對齊一般單音的中心：一個在上、一個在下，不是一個仍留在原位、另一個加在上面。不要因此拉大第一、二部間距或擴張整頁行距。八度雙音選用 J20 的簡寫。

J17 · 各音的升降記號、八度點、延音橫線必須隨該音一起縮放並居中。共用減時線放在整組下方，保留細縫；低八度點再依線層避開，力度使用既有獨立層。實際檢查小字仍可辨識、兩音八度點不相撞、整組中心正確，以及與相鄰部別的距離不變。不能只縮放原生音符而漏改文字覆層。

J18 · 四個八分音符若是「0＋三個有聲音」，減時線從第一個有聲音開始，不延伸到前面的八分休止 0。拍內其餘分組依實際拍號；2/2 一拍是二分音符，不能因移植 4/4 格式而無聲改拍號或演奏時值。

J19 · 口琴簡譜＋鋼琴五線譜是同一總譜的混合顯示：只對口琴 staff 隱藏五線和原生音頭，鋼琴大譜表、音頭、連音與所有原生 voices 均保持可見。不能用全曲 numbered 開關把鋼琴也隱藏。改用混合版型時，重新看拍號與速度，避免原生自動定位撞上簡譜手動拍號。

J20 · 創始使用者目前要求簡譜的八度雙音用一個數字加八度重奏記號，例如 `con 8va`，不疊寫兩個數字；五線譜不採此簡寫，仍寫上下兩個實際音。必須清楚標出開始、結束及跨行延續；兩個原生發聲音、力度與延音鏈均保留。一般移調 8va／8vb 只改記譜音區，與這項「另加一個八度同吹」不同。兩者同時存在時須各自核對實際發聲，不能一律刪除原有 ottava。這是新增偏好，不宣稱 Summer 已有同樣雙音範例。

J21 · 連結線的端點與弧身貼近所屬數字，保持可辨細縫，不能跑到上一個聲部或上一大行。非八度雙音的兩條線分置上音上方、下音下方，不能全部堆在同一側。逐條核對真正起訖音、跨小節與換行段；不要為移線改音長，或把同音延音與樂句圓滑線混成一條。八度簡寫只留下需要的可見線，隱藏的八度音仍保有完整播放延音。

J22 · 發現「神秘的點」先辨識來源：數字的八度點、覆層的節奏附點、原譜斷奏與透明原生音符／休止符外漏的附點是不同物件。只隱藏重複的原生附點顯示，不能刪掉 duration 的 dots 值或必要八度點。另把 Solo 等角色文字放回所屬聲部上方，避開前一部的數字、0 與八度點。

J23 · 三連音的橫桿與「3」視為同一組，貼近本組數字上方，仍留出升降記號與高八度點的空間；不能漂到前一聲部。數字音高 3、雙音的小字 3 與三連音標籤是不同物件，不能全文搜尋後一起移動。分組的實際起訖、原生 Tuplet 比例與發聲時值不變；放大對照原譜同段落，再看完整聲部間距。

J24 · J12 的四小節只是試排起點。長音多、攻擊點少的段落可增加每大行的小節數；密集段落相應減少，字級與最低字距仍須可讀。強制換行與最小小節寬會共同影響自動換行，必須看實際結果，避免最後一小節被另擠成空白很大的獨立大行。重新分行後，原先的逐段弧線、八度虛線與力度線座標不能直接沿用：依新大行重新核對所有跨行段，讓各段都留在所屬聲部，並保留真正音樂起訖。

## MuseScore 實作狀態

目前單曲原型採原生可播放音符加數字／線條覆層。它不是已完成的通用簡譜編輯器：修改原生音符不保證覆層自動更新。每次改譜必須重新比對兩層；音高、時值、力度與顯示八度都要有檢查。通用 adapter 尚待實作與跨作品驗證。
