# 從範例開始新曲

先閱讀 [編譜流程](workflow.md) 與 [Summer 版式驗證](tryout.md)，再依編制與記譜方式選擇 [The Entertainer 範例](../../pieces/entertainer/README.md) 的對應版本。六份可編輯譜、音樂事件與驗證紀錄都放在 `pieces/entertainer/`；其共用版式在 `layouts/summer/`。

先另存副本。原生音符負責播放，文字與線段負責簡譜；改音符後必須同步覆層，再在 MuseScore 檢查每拍減時線斷口、低八度點與力度、和弦、行首及結尾。這不是自動轉譜外掛。

檢查範例的驗證紀錄與雜湊，再替換曲名、作者與音樂內容。既有驗證只適用所列檔案與當時規則；新曲須依所選 profile 與最新規則重新檢查代表段落，再完成全曲並依 [檢查與交付](../rules/verification.md) 提供證據。
