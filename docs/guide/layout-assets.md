# 依編制選擇版式資產

這些資產提供字型、頁面、聲部配置及記譜設定，不指定任何曲目的音樂內容。先依 [編制與記譜版式](starting-a-piece.md) 確認需求，再選擇對應組合。

| 編制 | 記譜方式 | 樣式 | 聲部骨架 |
| --- | --- | --- | --- |
| 獨奏 | 五線譜 | [樣式](../../layouts/summer/Solo.mss) | [骨架](../../layouts/summer/Solo.mscx) |
| 獨奏 | 簡譜 | [樣式](../../layouts/summer/Solo_Numbered.mss) | [骨架](../../layouts/summer/Solo_Numbered.mscx) |
| 獨奏＋鋼琴 | 全五線譜 | [樣式](../../layouts/summer/Solo_Piano.mss) | [骨架](../../layouts/summer/Solo_Piano.mscx) |
| 獨奏＋鋼琴 | 口琴簡譜＋鋼琴五線譜 | [樣式](../../layouts/summer/Solo_Piano_Numbered.mss) | [骨架](../../layouts/summer/Solo_Piano_Numbered.mscx) |
| 二重奏 | 五線譜 | [樣式](../../layouts/summer/Duet.mss) | [骨架](../../layouts/summer/Duet.mscx) |
| 二重奏 | 簡譜 | [樣式](../../layouts/summer/Duet_Numbered.mss) | [骨架](../../layouts/summer/Duet_Numbered.mscx) |
| 二重奏＋鋼琴 | 五線譜 | [樣式](../../layouts/summer/Duet_Piano.mss) | [骨架](../../layouts/summer/Duet_Piano.mscx) |
| 四重奏 | 五線譜 | [樣式](../../layouts/summer/Quartet.mss) | [骨架](../../layouts/summer/Quartet.mscx) |
| 四重奏 | 簡譜 | [樣式](../../layouts/summer/Quartet_Numbered.mss) | [骨架](../../layouts/summer/Quartet_Numbered.mscx) |
| 五重奏 | 五線譜 | [樣式](../../layouts/summer/Quintet.mss) | [骨架](../../layouts/summer/Quintet.mscx) |
| 五重奏 | 簡譜 | [樣式](../../layouts/summer/Quintet_Numbered.mss) | [骨架](../../layouts/summer/Quintet_Numbered.mscx) |

樣式用於套用排版設定；聲部骨架用於建立對應的樂器與譜表。兩者都不能取代來源核對、編曲與新曲的實際驗證，也不是自動產生完整簡譜的外掛。

[簡譜字形樣板](../../layouts/summer/numbered-glyphs.xml)用於查考數字及附屬符號的設定；修改音符後仍須同步原生音符與可見覆層。原始資產的來源與雜湊見[來源紀錄](../../layouts/summer/provenance.json)，後續衍生組合仍須另查其製作與驗證範圍。

選定資產後，依 [版式驗證](tryout.md) 在正常 MuseScore 視窗檢查參考與當次作品的代表段落，再推進全曲。
