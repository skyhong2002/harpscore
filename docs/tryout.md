# 以 Summer 原檔驗證版式

首次使用、換字體或改渲染方法時，直接查看實際 Summer 參考檔，再用使用者要求的新曲檢查。同時保留參考的版本與實際渲染證據；不生成原創四小節練習。

## 先看真正的參考

- 在正常 MuseScore 視窗開啟使用者指定的 Summer 版本，檢查首頁、一般頁、密集段落及結尾。先確認檔名與內容，不能拿其他曲目或舊縮圖代替。
- 選對編制與記譜版本。`templates/layout/provenance.json` 記錄 Summer 八份來源檔的雜湊；`templates/layout/` 提供抽出的樣式、聲部設定與簡譜字形樣板。能讀取使用者的實檔時，直接複製另存並核對它的現況。
- 原檔無法取得時，只能說已讀取抽出的格式資產，不能宣稱已查看 Summer 的目前實際譜面。公開安裝包不附 Summer 第三方音符或音源。

## 用新曲的實際內容試排

- 複製相符版式，替換曲名、作者與音樂內容；原譜配器、拍號、弱起、反覆、音高、時值及力度仍以新曲來源為準。
- 挑新曲最密集及最容易出錯的段落，包含減時線分組、升降記號、八度點、延音、休止、和弦與力度。保留完整樂句，不以固定四小節截取或補寫練習。
- 在 MuseScore 查看實際渲染，放大核對數字與附屬符號、共用底線斷口、部距及行首／結尾。沒有要求 PDF 時直接保存正常視窗截圖；不能只檢查 XML 或邏輯分組。
- 簡譜覆層須與每個原生音符同步。改顯示基準只改八度點，不改播放音高；來源奏法記號不能擅自解讀成移調或新增音符。
- 若有雙音，核對兩個發聲音；五線譜保留兩音，簡譜非八度雙音對稱疊寫，八度雙音依 J20 顯示單數字與重奏記號。不以擴大部距補救，也不為試排自造第二音。

## 檢查後擴展全曲

保存改前後的音樂事件、參考檔雜湊、實際輸出及檢查紀錄。版面調整保持 performed pitch、onset、duration、velocity；若要改音樂，須有當次任務依據。

完成全曲後，逐頁檢查實際 MuseScore 畫面，另核對原生音符與可見簡譜；有要求 PDF 時再核對其輸出。正常開啟、檔案輸出、視覺檢查、播放器運作和實際聆聽分別記錄，不能互相代替。任何修正後，重新檢查受影響段落及最終輸出。
