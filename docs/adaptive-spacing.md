# 依內容調整相鄰聲部間距

當簡譜和弦代號、連音標籤或連線碰到相鄰聲部時，先看實際渲染。只替真正缺空間的大行增加最小部距；其他行維持正常密度。不可把一處碰撞轉成全曲加寬，也不靠任意橫移符號破壞拍點對齊。

## 適用範圍

`scripts/adaptive_staff_spacing.py` 適用 MuseScore 的兩個相鄰、單線譜表之手動簡譜文字覆層。可指定任意一組聲部，不限 Chord／Bass。一般部距 `--base` 由該曲已核對的版式決定；示例數值不是通用標準。`--clearance` 是實際字形間的最低淨距，可依字級和印刷需求設定。

這是「渲染 → 量測 → 提案 → 寫入副本 → 重開驗證」工具，不是 MuseScore 內的即時排版引擎，也不適用鋼琴五線譜、任意原生音符或多線譜表。文字基線由 StaffText 的頁面位置減手動 offset 取得；自動避讓的文字或不一致基線會拒絕處理。未被幾何讀取器收錄的標記仍需看圖。

## 取得當版幾何

套件附 `plugins/HarpScoreGeometry/HarpScoreGeometry.qml`。將整個資料夾複製到 MuseScore 的使用者插件目錄，在 Manage plugins 啟用，再從 Composing/arranging tools 執行 HarpScore Geometry。先正常儲存指定曲目，使用 Page view 並完成排版；插件只讀取目前開啟的譜，將 `renderer-geometry.json` 寫在插件旁，會覆寫上次快照。插件目錄須可寫；立即將 JSON 複製到該曲工作目錄，避免下一首覆蓋。

讀取器以已用過的 Geometry R9 為基礎，收錄文字、力度、重音、可見線條、跨行續段及原生事件。原生透明音符不是覆層的字形邊界。JSON 的 `error` 必須為 null；核對 `scoreName`、小節數、頁數與實際視窗。舊 R9 JSON 亦可使用。插件只提供幾何，不宣稱全譜無碰撞；新版插件的安裝與實際輸出要在使用環境確認。

## 使用方式

先備份，保留原譜。以下路徑均相對於 skill 根目錄，檔名可自行指定。聲部從 1 起算，`--lower` 必須緊接 `--upper`。下面的 7.3 僅是某版簡譜的一般基線距離示例。

```sh
python3 scripts/adaptive_staff_spacing.py plan input.mscz renderer-geometry.json spacing-plan.json --upper 3 --lower 4 --base 7.3 --clearance 0.35
python3 scripts/adaptive_staff_spacing.py apply input.mscz spacing-plan.json output.mscz
```

`plan` 不改譜，輸出各行目前／所需間距、需要補空間的小節與輸入雜湊。提案綁定當時的 MSCZ；原檔改動後 `apply` 會拒絕舊提案。雜湊防止套用期間換錯檔，不能證明最初 JSON 就來自這份譜，配對仍須在取樣時確認。

如果本來已有全曲 `distOffset`，先確認那是要撤銷的固定加寬，再於 `plan` 加上 `--reset-global-offset`；預設不移除既有全曲設定。輸出必須是不存在的新檔，不能覆寫來源。

工具只撤回自己留下且未被使用者更改的 `vspacerUp`，再按新內容計算；保留手動 spacer。若回報 `preserved_manual_spacer_measures`，須檢查該處：手動間距可能大於需求而仍留白，也可能小於需求而仍碰撞。不要將這種結果寫成自動完成。自行編輯過的 spacer 也保留。原生最小 spacer 隨小節移到新行，但改音、字型或重新分行後仍須重新取得幾何並計算。

## 計算與驗收

- 依頁與大行隔離座標，不比較不同頁的同位置。
- 只比較水平方向相交的實際字形、重音與可見線條框；不以所有物件的最高／最低值一律撐大整行。
- 將上下物件位置換算為各自譜表基線的相對座標，得到所需基線距離，再與正常部距取較大值。已增加的部距不會在重算時再累加。
- 將最小間距附在有需求的小節；跨小節線段的碰撞涵蓋所有受影響小節。MuseScore 讓該大行採用最大需求，其他行不變。多組相鄰聲部依序處理，每次重新渲染，不共用過期提案。
- 譜面包含未量測的符號、曲線框過度保守、隱藏聲部或人工 spacer 時，幾何只能指出候選。看圖確認字形細縫與正常密度。

套用後正常儲存／重開；比較全部音高、起音、時值、力度、速度與原生連線端點。記錄每頁大行數、各行實際部距、最小淨距，以及重新計算是否穩定。檢查加寬行、普通行、上下相鄰大行、跨行八度線與頁首頁尾。相同需求重算應穩定；若分行改變，重新量測，不能只重複套用舊位移。

已完成的作品試驗中，45 大行只有兩行需要補空間，其餘43行恢復一般部距；保留九頁、每頁五行及完整音樂資料。這是單曲的實際 renderer 證據，不是所有曲目通過。公開測試使用最小幾何和 XML 案例，不附第三方全譜。
