# 從一首新曲開始

## 最少只需要三項

提供曲名與參考音源或原譜、演出編制、演奏程度。其餘可以沿用已選的風格設定。若未確定，先說明採用的假設；只有會改變音樂結果的問題才需要追問。

W01 · 建立需求：記錄參考版本、需要的段落或完整曲長、調性、速度、樂器型號與實際音域、演奏程度、伴奏形式、需要的版本。輸出格式與發布位置要分別記錄。

W02 · 核對來源：先建立段落與聲部清單。把開頭打擊、主旋律、和聲、副旋律、低音與尾奏都列入；不確定的音寫成待核對項目，不把簡化當成已轉錄完成。可依法取得的音訊下載是來源取得步驟，下載成功不代表已聽寫。

W03 · 編曲：先確保完整旋律與曲式，再分配角色。以有主旋律、密集節奏、換部與結尾的代表段落檢查可吹性；發現問題先修編曲，再推進全曲。不能只檢查容易的前八小節。

W04 · 五線譜與簡譜：由同一份已核對音樂資料衍生。顯示規則不能偷偷改變音高、時值或力度。若為呼吸做縮短或簡化，應列為音樂改動。

W05 · 檢查：依驗收手冊核對節奏、聲部分配、音域、渲染與實際播放。首次使用新軟體或輸出途徑先小規模驗證，不大量啟動不穩定的轉檔程序。

W06 · 交付：依需求輸出可編輯譜、PDF、示範與伴奏。PDF 可暫停；不要因為驗收流程寫到 PDF 就忽略使用者的暫停指示。發布到網站或聊天平台另依該次授權。

## 四種變更要分開

- 轉錄修正：更接近參考音源，記錄改正的聲部與位置。
- 演奏改編：簡化、換音區、改配器、呼吸與接句，記錄理由。
- 記譜改寫：連結線、符尾分組、簡譜延音與八度顯示，保留實際音樂事件。
- 排版調整：字型、間距、換行、頁首頁尾，不更動音樂。

## 一首一資料夾

建議使用 `01_Scores`、`02_PDF`、`03_Audio`、`04_Edit_Exports`。版本號放在 metadata 與變更記錄；日常檔名可以穩定。舊稿放在作品目錄外的 Archive，保留檔案清單與雜湊，不讓舊稿混入使用中的版本。

總譜、演出用合併譜、個別分部是不同交付項目。不要看到二重奏就預設輸出兩份單獨口琴分部。
